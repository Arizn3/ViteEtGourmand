        Ce projet a suivi de bonnes pratiques de versionnement avec Git.

        Le développement principal a été réalisé sur une branche "develop", avec des commits format Angular en anglais.

        Chaque fonctionnalité importante était développée sur une branche dédiée, puis fusionnée sur la branche "develop" après validation et tests.

            Exemple de workflow utilisé :

                main
                └── develop
                    └── feature/filtreDynamique

            Création d’une branche de fonctionnalité :

                git switch -c feature/filtreDynamique

            Développement et tests de la fonctionnalité.
            Fusion dans la branche develop :

                git merge feature/filtreDynamique

            Suppression de la branche de fonctionnalité :

                git branch -d feature/filtreDynamique

        Après stabilisation du projet, la branche "develop" a été supprimée afin de conserver un dépôt GitHub plus propre, celle visible sur le dépôt actuel est
        une nouvelle branche "develop" crée spécialement pour la mise en place de la documentation.
